A personal intelligence system built to turn questions into clear, useful next steps. A.R.I.S. brings together research, analysis, and action in a single adaptive workflow for data and decision-making work.

## Core stack

- Python
- SQL
- R
- Power BI

## What A.R.I.S. does

- Makes sense of scattered research and raw information
- Finds useful patterns and signal in noisy data
- Turns questions into actionable decisions and plans
- Supports a clearer, faster path from insight to execution

## ORD model

Observe. Reason. Decide.

1. Observe the context
2. Reason through the patterns
3. Decide the next move

## Project structure

- `index.html` — landing page / portfolio-style website
- `.github/workflows/pages.yml` — GitHub Pages deployment automation
- `.nojekyll` — required for static asset hosting compatibility

## Run locally

Open the site directly in a browser:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Deployment

This project is set up for GitHub Pages.

1. Push to GitHub
2. Open repository Settings
3. Go to Pages
4. Set Source to GitHub Actions
